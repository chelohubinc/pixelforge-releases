## About PixelForge Studio

**PixelForge Studio** is a desktop application for AI-powered image upscaling and enhancement.

Built around specialized Real-ESRGAN models and ONNX Runtime, it provides tools to increase image resolution, refine details and process multiple images through a focused desktop workflow.

This repository is the official distribution hub for PixelForge Studio. It hosts published releases, downloadable installers and release notes.

**This is not the application's source code repository.**

## Features

- **AI Image Upscaling** — Increase image resolution by 2× or 4×.
- **Specialized AI Models** — Choose between models designed for general images, anime and image enhancement.
- **CPU & GPU Processing** — Select an available processing device according to your hardware.
- **Smart Tiling** — Process large images in smaller sections to help manage memory usage.
- **Batch Processing** — Process multiple images in one workflow.
- **Before & After Comparison** — Inspect original images alongside enhanced results.
- **Image Finishing** — Apply additional finishing options, including metadata removal and subtle visual adjustments.
- **Flexible Export** — Export enhanced images in PNG, JPEG and WebP formats.

## Report a Bug

Encountered a problem while using PixelForge Studio?

**[Open an issue on GitHub →](https://github.com/chelohubinc/pixelforge-releases/issues/new/choose)**

When reporting a problem, include as much relevant information as possible:

- Operating system and version.
- PixelForge Studio version.
- Selected AI model and upscaling factor.
- Processing device (CPU or GPU).
- Original image dimensions and format.
- Steps to reproduce the problem.
- Complete error message or relevant logs.

Please avoid attaching private images, passwords, access tokens or other sensitive information.
